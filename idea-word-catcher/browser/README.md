# Word Catcher 浏览器扩展（Chrome / Edge 通用）

与 IDEA 插件 **Word Catcher ≥ 1.3.0** 共享同一个生词本：网页里取词、网页生词高亮、
生词卡片自测、导出 CSV——数据和操作全部与 IDE 端同源同逻辑。

## 前提

- IDEA 里已安装 Word Catcher 1.3.0+，且 **IDEA 正在运行**（扩展通过插件内嵌的本地服务
  `127.0.0.1:18091` 读写生词本，服务随 IDE 启停；IDE 关闭时扩展会显示“未连接”）。
- 同时开两个 IDE 实例时，只有第一个实例能占用 18091 端口。

## 安装（开发者模式加载）

1. 打开 `chrome://extensions`（Edge 为 `edge://extensions`）
2. 打开右上角「开发者模式」
3. 点「加载已解压的扩展程序」，选择本 `browser/` 目录

## 用法

### 取词（与 IDE 同款操作）
- 选中单词 → 右键菜单「记入生词本“…”」，或按 `Alt+Shift+W`（与 IDE 快捷键一致）
- 结果显示在扩展图标的 badge 上：`✓3` 成功（第 3 次遇到）、`×` 不是英文单词、`!` IDEA 未运行
- 自动记录：所在句子作为上下文、页面标题 · 站点作为来源；去重计数、查词典、词根拆解
  都由 IDEA 插件完成（多源词典降级与 IDE 完全一致），工具窗实时联动刷新

### 网页生词高亮
- 所有 http/https 页面自动高亮已记生词（忽略大小写、词边界），浅色 `#FFE9A8` / 深色 `#5C4A1E`
- 与 IDE 编辑器高亮同规则：页面变化 300ms 防抖重刷，超过 200 万字符的大页面跳过
- 弹窗工具栏「高亮」一键开关；取词 / 打开弹窗 / 切换标签页时自动同步词表

### 弹窗（点扩展图标）
- 列表：单词 / 释义 / 次数，点行展开详情（音标、词根、例句、上下文、来源）
- 详情里：🔊 朗读（与 IDE 同款系统 TTS，走插件服务，离线可用；IDEA 未运行或朗读失败时退回浏览器语音，音色可在工具栏下拉框选择——Edge 还提供在线 Natural 音色，效果最好）、删除
- 工具栏：高亮开关 ｜ 生词卡片 ｜ 补全词典（间隔 300ms，同 IDE）｜ 复制全部单词（可直接导入 Anki）
  ｜ 导出 CSV（与 IDE 导出完全同格式，UTF-8 BOM）

### 生词卡片
- 随机顺序翻卡自测：正面 单词 + 音标 + 上下文提示 → 显示释义 → 背面 词性释义 / 词根 / 例句
- 认识 / 不认识 / 跳过 / 朗读，结束统计（与 IDE 生词卡片同流程）

## 数据与端口

- 所有读写都走 IDEA 插件进程（唯一写入方），数据文件仍是
  `IDE配置目录/options/wordCatcher.xml`——浏览器取词后 IDE 工具窗立即出现，IDE 里删除后
  浏览器下次同步即消失，永不冲突。
- 本地服务只绑定 `127.0.0.1:18091`，不出本机。

## 已知限制

- IDEA 关闭时扩展只读不可写（明确提示“未连接”，不会丢数据）
- `file://` 页面默认不取词不高亮；如需要，在扩展详情页打开「允许访问文件网址」
- `Alt+Shift+W` 是建议快捷键，若被浏览器 / 其他扩展占用，到
  `chrome://extensions/shortcuts` 手动指定

## 目录说明

```
browser/
├── manifest.json       # MV3 清单
├── api.js              # 插件本地 HTTP API 封装（端口/校验规则与 IDE 端一致）
├── background.js       # 取词（右键/快捷键）、badge 反馈、词表同步与广播
├── highlight.js        # 网页生词高亮（content script）
├── popup.html/js/css   # 弹窗：列表 / 详情 / 工具栏
├── flashcards.html/js/css # 生词卡片自测页
├── icons/              # 图标（可用 tools/make_icons.ps1 重新生成）
└── tools/make_icons.ps1
```
