# 浏览器工具箱（browser-toolbox）

个人开发小工具集合的 Chrome 扩展（Manifest V3）。第一个工具是 JWT 解析，后续工具持续集成。

## 安装

1. Chrome 打开 `chrome://extensions/`
2. 右上角开启「开发者模式」
3. 「加载已解压的扩展程序」选择本目录
4. 工具栏拼图图标里把「浏览器工具箱」固定到工具栏

## 功能

| 工具 | 说明 |
|---|---|
| JWT 解析 | 粘贴 token 自动解码 header/payload；显示用户、角色标签、过期倒计时；支持 JSON 复制、深色模式 |
| JSON 格式化 | 树形折叠视图（点击 {}/[] 折叠展开，超 16 行节点自动折叠，一键展开/折叠全部）与纯文本视图切换；缩进 / Tab / 压缩单行、按键名排序；容忍粘贴杂文自动截取；Python dict（单引号 / None / False / 未引号键）自动修复；解析失败给出错行 + `^` 定位与原因提示；语法高亮、复制、深色模式 |
| 当前时间 | 仿 time.is 的大时钟版式（12/24 小时制切换）；**世界时钟**：世界地图上标注约 1000 个城市点（GeoNames 按人口选取，覆盖 240+ 国家/地区，中文名），点击地图任意位置自动加入离点击点最近的城市（悬停显示城市名+当地时间+距离，亮色点=已加入），城市卡为 SVG 指针钟（秒针连续扫动）+ 下方城市名与 HH:MM，☀/🌙 昼夜标记、跨天 ±1 天徽标，悬停卡片可移除，列表存本机（兼容旧版纯时区数据迁移）；地图背景为 Natural Earth 陆地轮廓本地生成的 SVG，CSS mask 随主题着色；时区信息（IANA 名称、UTC 偏移、夏令时状态）；Unix 时间戳（秒/毫秒实时 + 复制）；本地/UTC ISO 8601、UTC 字符串、中文长格式一键复制；ISO 周数、年内天数、季度、闰年、农历（干支生肖，支持 1900–2049 年）。直接读本机系统时钟，城市时间用浏览器时区库换算，不联网校时 |
| 位置 / GPS | **页签式三视图**（📍定位 / 🏠收件地址 / 🚗出行规划，记住上次停留；高德 Key 状态在顶栏徽章全局可见，点击开设置面板）：定位视图调用浏览器 Geolocation 获取当前坐标：纬度/经度/精度/海拔/航向/速度/定位时刻；WGS-84、GCJ-02（火星坐标）、BD-09 三套坐标系本地换算 + 度分秒格式；高德/百度/Google/OSM 地图链接（点击才打开）；可切换定位结果的坐标解读方式，修正大陆 Wi-Fi 定位的坐标系偏差。manifest 声明了 `geolocation` 权限以免重复弹授权框。地址搜索候选以输入框下拉浮层展示。**外卖 / 收件地址**：可选配置高德「Web服务」Key（免费，存本机，输入框密文显示并禁止复制/剪切/右键），定位后调高德逆地理接口换回标准地址、省市区门牌号、附近建筑候选（按距离排序，点选填入，多候选容错）；楼栋/楼层/房间号人工填写（纯数字自动补「层/室」），生成一行外卖地址一键复制；多条地址保存本机（chrome.storage.local），支持复制/编辑/删除。**地址搜索 / 路径规划**：起点/终点输入后自动搜索，POI 关键词 + 地理编码双通道合并候选（地标/地址分类标注），「地铁站2号口」这类出口号输入自动逐级放宽重搜（剥号口→剥地铁站）；可选城市限定搜索范围；候选点选设点，起点可用当前定位（页面打开即自动获取位置，起点未设时自动填入；按钮无缓存时现场定位，不再要求先去定位页）；**多途经点**：可添加最多 10 个途经点（上移/下移调序、移除），A→B→C→D 按相邻点拆成多程逐段查询，第一程/第二程/…页签切换查看，页签栏显示全程累计距离与耗时，失败的程在对应页签内标 ⚠；支持驾车（含打车费参考）/公交（多方案：乘车线路、上下车站、步行段）/步行/骑行四种模式，可折叠分段步骤，一键跳转高德网页版导航；公交自动取本程起点城市（adcode）；校验与接口错误就地显示在查询按钮下方 |
| 二维码生成 | 网址/任意文本转二维码：纯本地编码（内嵌 MIT 协议 qrcode-generator，中文 UTF-8），自动选版本；白底黑码 + 四模块留白保证扫码率，深色模式不变；纠错级别 L/M/Q/H 可选；下载 PNG / 复制图片 / 复制文本；最近 8 条生成记录存本机点击回填；支持右键选中文字直接生成 |
| 矩阵计算器 | 双矩阵 A/B（1–8 维步进调整）：矩阵乘法/加减、转置、行列式（部分主元高斯消元）、逆矩阵（Gauss-Jordan，奇异检测）、迹、秩、数乘；改任意数字实时重算；格子里直接粘贴 Excel/TSV/空格表格自动铺满调尺寸；单位阵/清零预设；结果复制为 TSV（贴 Excel）或文本；顶栏「草稿已保存」可点击查看已存内容（复制 JSON / 清除）；页面底部附运算法则速查（乘法/行列式/逆/迹/秩定义与常用性质，随时核对手算）；**草稿自动保存**（尺寸/数值/运算/系数存本机，重开原样恢复） |
| 微积分计算器 | 迷你符号引擎（自写解析器，支持隐式乘法 2x / 3sin(x)、** 幂、pi/e 常量）：**符号求导**一阶/二阶（乘积/商/幂/链式法则全覆盖 + 自动化简 + 法则说明）；**定积分**自适应复合辛普森（收敛过程表，函数图像高亮积分区域）；**极限**双侧数值逼近判定；**泰勒展开**逐阶系数表 + 多项式；canvas 函数图像（y 分位数自适应、实时刷新）；草稿自动保存；底部微积分法则速查（求导法则表等） |
| 右键菜单 | 选中网页里的 JWT / JSON 文本 → 右键「工具箱：…」解析或格式化；选中任意文字 →「工具箱：生成选中文字的二维码」 |

除「外卖 / 收件地址」外，所有工具仅在本地处理，不发起任何网络请求；JWT 签名验证需服务端公钥，工具不验签。时间工具直接读系统时钟（无原子钟对时）；定位工具的坐标换算全在本地完成，地图链接由用户点击后在浏览器打开；二维码编码全在本地（qrcode-generator，MIT）。出行规划与收件地址是联网点：仅在点「查询附近地址」或配置了 Key 后定位成功/搜索地址时，把坐标或地址文本发给 `restapi.amap.com`（manifest 中以 `host_permissions` 精确限定该域名），不发送任何其他数据；Key 与地址列表只存本机。楼层/门牌号任何接口都没有，只能人工核对填写。

## 如何新增一个工具（两步）

1. `tools/` 下新建目录，如 `tools/timestamp/`，写 `index.html`（引用 `../common.css` 即获得统一的卡片/按钮/深色主题样式）
2. `tools/registry.js` 里加一条：

```js
{
  id: 'timestamp',
  name: '时间戳转换',
  icon: '⏱',
  desc: 'Unix 时间戳与日期互转',
  path: 'tools/timestamp/index.html'
}
```

popup 会自动渲染新工具入口。

## 目录结构

```
browser-toolbox/
├── manifest.json        # MV3 清单（版本号唯一来源）
├── bg.js                # service worker：右键菜单
├── gen_icons.py         # 图标生成脚本（Pillow），改色后重跑
├── icons/               # 16/48/128 png
├── popup/               # 点图标弹出的工具入口
└── tools/
    ├── registry.js      # 工具注册表（唯一要维护的清单）
    ├── common.css       # 工具页公共样式（深/浅主题）
    ├── jwt-decoder/     # JWT 解析工具
    ├── json-formatter/  # JSON 格式化工具
    ├── time/            # 当前时间工具（大时钟 / 时区 / 时间戳 / 农历）
    └── location/        # 位置 / GPS 工具（定位 / 坐标转换 / 地图链接）
```
