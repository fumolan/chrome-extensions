      微积分法则速查（求导法则表 · 积分/极限/泰勒，随时核对手算）

      求导法则：

      常数 (c)′ = 0；幂 (xⁿ)′ = n·xⁿ⁻¹；和差 (u ± v)′ = u′ ± v′。
      乘积 (u·v)′ = u′·v + u·v′；商 (u/v)′ = (u′v − u·v′)/v²；链式 (f(g))′ = f′(g)·g′。

      常用导数：sin→cos；cos→−sin；tan→1/cos²；ln→1/x；log₁₀→1/(x·ln10)；exp→exp；√→1/(2√)；|x|→sign(x)；sinh→cosh；cosh→sinh；tanh→1/cosh²；asin→1/√(1−x²)；acos→−1/√(1−x²)；atan→1/(1+x²)。

      定积分：微积分基本定理 ∫ₐᵇ f = F(b) − F(a)（F 是原函数）。本页用复合辛普森法则做数值积分：区间等分 n 段后每两段用抛物线逼近，逐次加倍 n 直到结果收敛，误差随 n 快速下降。面积在图像上以高亮区域显示。

      极限：本页从 a 的左右两侧以逐步缩小的距离逼近取值。左右极限相等 → 极限存在；同号发散 → ±∞；不等 → 不存在（跳跃点）。

      泰勒展开：f(x) ≈ Σₖ f⁽ᵏ⁾(x₀)/k! · (x−x₀)ᵏ。例：sin x 在 0 处五阶 = x − x³/6 + x⁵/120。
