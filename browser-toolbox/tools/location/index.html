如何获取？

获取当前位置

台式机/笔记本通常没有 GPS 芯片，浏览器用 Wi-Fi / IP 估算位置，精度几十米到数公里；带 GPS 的设备精度更高。
  • 坐标系：GPS 芯片原始输出 WGS-84；中国大陆的 Wi-Fi/IP 定位结果常按 GCJ-02（火星坐标）给出。高德/腾讯地图用 GCJ-02，百度地图用 BD-09，Google/OSM 用 WGS-84。若高德链接偏差约 500 米，把「定位结果按」切到 GCJ-02 即可。
  • 坐标换算全部在本地完成；地图/导航链接在你点击时才于新标签页打开。

  • 联网说明（共用同一个 Key，均只发往 restapi.amap.com）：①「收件地址」把当前坐标发给逆地理接口换标准地址；②「出行规划」把输入的地址文本发给地理编码/POI 接口、把起终点坐标发给路径接口。楼层/房间号任何接口都没有，只能人工填写。
  • 「地铁站2号口」这类输入：POI 库多不收录出入口，搜不到时会自动去掉「N号口」→「地铁站」逐级放宽重搜，并在候选上方提示。
