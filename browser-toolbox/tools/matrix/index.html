      运算法则速查（随时核对手算用）

      记号：A 是 m×n（m 行 n 列）矩阵，A[i][j] 表示第 i 行第 j 列元素；I 是单位阵。

      矩阵乘法 A × B（m×n · n×p → m×p，A 的列数必须 = B 的行数）：
      (AB)[i][j] = Σₖ A[i][k] × B[k][j]（A 的第 i 行与 B 的第 j 列对应相乘再相加）。注意 AB ≠ BA。

      加 / 减 A ± B：必须同形状，逐元素相加/减。(A ± B)[i][j] = A[i][j] ± B[i][j]。

      转置 Aᵀ：行列互换，(Aᵀ)[i][j] = A[j][i]。性质：(Aᵀ)ᵀ = A；(AB)ᵀ = BᵀAᵀ；(A ± B)ᵀ = Aᵀ ± Bᵀ。

      数乘 k·A：每个元素乘 k。(kA)[i][j] = k·A[i][j]；det(kA) = kⁿ · det(A)（n 为阶数）。

      行列式 det(A)（方阵专属）：
      2×2：|A| = ad − bc（a=左上, b=右上, c=左下, d=右下）。
      3×3：对角线法则——三条主对角线方向乘积取正、三条副对角线方向乘积取负，求和。
      性质：|AB| = |A|·|B|；|Aᵀ| = |A|；交换两行 det 变号；某行乘 k → det × k；某行加上另一行的倍数 → det 不变（消元依据）；某行全为 0 → det = 0。

      逆矩阵 A⁻¹（方阵且 det ≠ 0 才存在）：
      定义：A·A⁻¹ = A⁻¹·A = I。
      2×2 速算：A⁻¹ = (1/det) × [[d, −b], [−c, a]]（主对角交换、副对角变号）。
      伴随矩阵法：A⁻¹ = adj(A) / det(A)。
      性质：(AB)⁻¹ = B⁻¹A⁻¹；(kA)⁻¹ = (1/k)·A⁻¹（k≠0）；(Aᵀ)⁻¹ = (A⁻¹)ᵀ。

      迹 tr(A)（方阵专属）：主对角线元素之和。性质：tr(A±B) = tr(A) ± tr(B)；tr(AB) = tr(BA)；tr(kA) = k·tr(A)。

      秩 rank(A)：化为行阶梯形后非零主元行的个数 = 行（列）向量组中线性无关的最大个数。性质：rank(Aᵀ) = rank(A)；rank(AB) ≤ min(rank A, rank B)；n 阶方阵 rank = n ⇔ 可逆 ⇔ det ≠ 0。

      提示：页面上的「计算过程」卡会按这些法则逐步展开你当前输入的每一步算式，可直接对照核验。
