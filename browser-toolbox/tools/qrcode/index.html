关于二维码：技术原理 · 作者 · 本页编码过程（感兴趣再展开）

技术来源：QR 码（Quick Response Code）是日本 Denso Wave（电装公司）工程师原昌宏（Masahiro Hara）团队 1994 年为追踪汽车零部件发明的矩阵式二维条码。Denso Wave 持有「QR Code」商标，但明确开放了专利实施权，所以任何人都能自由生成使用；官方科普站 qrcode.com。

本页用的编码库：qrcode-generator，作者 Kazuhiko Arase，MIT 协议，全部编码在本页本地完成、不联网。

一次二维码编码的思想（随你的输入实时更新）：

  1. 选模式：QR 有数字/字母/8 位字节/汉字等多种压缩模式，本页统一用 Byte + UTF-8（中文先转成 2–3 字节的 UTF-8 序列再编）。
  2. 选版本：QR 共 1–40 版（版本 1 为 21×21 模块，每升 1 版边长 +4），按「数据字节数 + 纠错级别」自动选最小能装下的版本。当前：—。
  3. 加纠错：数据切成 8 bit 码字后，用 Reed–Solomon 纠错算法算出校验码字接在尾部——所以码面破损、遮挡一角仍扫得出。当前级别 —。
  4. 填矩阵：先放三个「回」字定位角、时序图案与对齐图案确定坐标系，再把全部码字按之字形填进剩余格子。
  5. 选掩码：同一份数据有 8 种黑白翻转方式，逐个按「避免大面积同色块 / 伪定位图案」规则打分取最优——这就是为什么内容改一个字，整张码看起来完全不同。

一句话：二维码 = 分级冗余的纠错编码 + 固定坐标系图案 + 掩码择优，三者叠加让扫码器既能找到码、又能读出数据、还能容错。
