# 更新日志（Changelog）

版本号以 `extension/manifest.json` 的 `version` 为单一来源；扩展模式下界面自动读取并显示，
普通网页方式打开时使用 `app.js` 中的兜底常量（改动版本时需同步修改这两处）。

## 1.6.3（2026-11-03）

- **新笔记默认标题**：新建笔记自动注入头部标题行「11月3日 14:30」（类有道云笔记），
  不再出现无标题笔记；光标落在标题行末尾，可续写标题，回车 / ↓ 进入正文
- 仅保留默认标题、未写任何正文的新笔记拦截保存（提示「笔记内容为空」），避免误存空笔记；
  改动标题或写了正文后照常保存

## 1.6.2（2026-10-20）

- **标题与正文合一（类 macOS 备忘录）**：移除独立标题输入框，正文首行即标题
  （首行自动大字加粗显示）；保存时取首行文字作标题，旧笔记打开时标题自动注入为首行，数据无需迁移
- 项目 / 分组 / 置顶移到富文本工具栏尾部**右对齐**，标题行占位彻底取消，正文区再省一行
- 导出 HTML / Markdown / PDF 时自动剥离首行标题（避免标题在导出文件中出现两次）；
  首行为列表 / 表格 / 代码块时不取标题

## 1.6.1（2026-10-20）

- **编辑区空间最大化**：移除顶部横条，「⚙ 设置」移到最左图标栏底部（存储模式见图标悬停提示），
  正文区上下各多出一行空间
- 标题行合并：「标题 + 项目 + 分组 + 置顶」压缩为一行，项目 / 分组去文字标签只留下拉框，
  置顶改为纯图标按钮（悬停见提示）
- 工具栏、底部操作栏压缩变矮；删除改为图标按钮，保存按钮精简为「保存」（快捷键 Ctrl+S 不变）
- 左侧目录 / 列表两栏收窄（178→150 / 292→250），编辑区内边距收窄，正文可读面积更大

## 1.6.0（2026-10-10）

- 侧栏改版（参考有道云笔记）：改为「目录树 + 笔记列表」两栏侧栏；
  列表顶部为搜索框（新增 `Ctrl+Shift+F` 聚焦），底部显示「总共 N 项」
- 最左侧新增常驻图标栏（新建 / 最新 / 置顶 / 目录），底部提供 **1 / 2 / 3 栏** 三个视图切换按钮
  （3 栏＝目录+列表+编辑器，2 栏＝列表+编辑器，1 栏＝仅编辑器；视图与所选范围均记忆），
  替代原顶栏 ☰ 侧栏开关
- 界面显示当前版本号：顶栏品牌旁与设置弹窗内各一处
- 移除图标栏重复的设置入口，设置统一从顶栏「⚙ 设置」进入

## 1.5.0 及更早

- 富文本编辑（标题/列表/颜色/高亮/链接/图片/代码块等）、Ctrl+S 保存
- 项目 / 分组两级组织 + 置顶；笔记搜索；附件（粘贴 / 拖放 / 上传）
- 导出 HTML / Markdown / PDF
- 双存储模式：本地 IndexedDB（默认）/ REST 服务器（Node.js + SQLite，兼容 PostgreSQL / MySQL）
