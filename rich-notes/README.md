# 富文本笔记（浏览器扩展 + 可选数据库服务器）

一个 Chrome / Edge 浏览器扩展：富文本编辑器 + 数据库存储。

- **本地模式（默认）**：数据存在浏览器内置数据库 **IndexedDB** 中，开箱即用，不需要任何服务器。
- **服务器模式（可选）**：连接本项目自带的后端（**纯 Node.js + SQLite，零依赖**），数据落在 `server/notes.db` 文件里，可跨设备/备份/用 SQLite 工具查看。

## 目录结构

```
rich-notes/
├─ extension/            # 浏览器扩展（Manifest V3）
│  ├─ manifest.json      # 扩展清单（version 字段为应用版本的单一来源）
│  ├─ bg.js              # 点击图标打开应用
│  ├─ app.html/css/js    # 主界面（两栏侧栏 + 富文本编辑器，设置弹窗显示版本号）
│  ├─ db.js              # IndexedDB 封装（本地数据库）
│  ├─ storage.js         # 存储适配层（本地 / 远程服务器切换）
│  ├─ md.js              # HTML → Markdown 转换器（导出 .md 用）
│  └─ icons/             # 图标（由 gen_icons.js 生成）
├─ server/               # 可选的后端数据库服务
│  ├─ server.js          # REST API + SQLite（零依赖，Node.js >= 22.5）
│  ├─ package.json
│  └─ 启动服务器.bat
├─ CHANGELOG.md          # 版本更新日志
└─ gen_icons.js          # 图标生成脚本（node gen_icons.js）
```

## 一、安装扩展（本地模式，开箱即用）

1. 打开 Chrome，地址栏输入 `chrome://extensions`
2. 打开右上角的 **开发者模式**
3. 点击 **加载已解压的扩展程序**，选择本项目的 `extension` 文件夹
4. 点击浏览器工具栏中的扩展图标，即可打开笔记应用

> Edge 同理：`edge://extensions` → 开启「开发人员模式」→「加载解压缩的扩展」。

## 二、连接数据库服务器（可选）

需要 Node.js >= 22.5（推荐 23+）。支持三种数据库：**SQLite（默认，零依赖）/ PostgreSQL / MySQL**。

### 配置方式：编辑 `server/.env`

所有配置集中在 `server/.env`（参考 `.env.example`，改完重启 `node server.js` 生效）：

```ini
DB_DRIVER=sqlite          # sqlite | postgres | mysql，改成哪个就用哪个
PORT=3001                 # 服务端口
# DB_FILE=notes.db        # SQLite 数据库文件路径

# PostgreSQL 连接串（目标库不存在会自动创建）
DATABASE_URL=postgres://用户名:密码@localhost:5432/rich_notes

# MySQL 连接串（目标库不存在会自动创建）
# DATABASE_URL=mysql://用户名:密码@localhost:3306/rich_notes
```

- 同名环境变量优先级高于 `.env`（命令行临时覆盖：`DB_DRIVER=mysql node server.js`）
- PostgreSQL / MySQL 首次使用需在 server 目录 `npm install` 安装驱动（pg / mysql2，双击
  `启动服务器.bat` 会自动判断并安装）
- **自动建库**：`DATABASE_URL` 里的库名（如 `rich_notes`）不存在时服务会自动创建，
  无需手工执行 CREATE DATABASE；库名仅限字母数字下划线
- `.env` 含数据库密码，已加入 `.gitignore`，不要提交到代码仓库
- MySQL 大附件较多时建议把 `max_allowed_packet` 调到 256M

三种数据库的 REST API 完全一致，扩展端无需任何改动。

### 切换存储模式 + 一键迁移

1. 扩展里点击 **⚙ 设置**
2. 选择 **REST 服务器（Node.js + SQLite）**，地址填 `http://localhost:3001`
3. 点击 **测试连接**（应提示"连接成功 ✓"）
4. （可选）点击 **⬆ 上传本地笔记到服务器**：把本地 IndexedDB 里的全部笔记
   上传到服务器，服务器上同 ID 的笔记会被本地版本覆盖；完成后切换到服务器模式
   即可在所有设备共享同一份数据
5. 点击 **保存设置**

> 注意：本地模式和服务器模式的数据相互独立，切换模式本身不会迁移数据，
> 需要用第 4 步的迁移按钮。

## 三、功能与快捷键

- 富文本：标题、加粗、斜体、下划线、删除线、有序/无序列表、引用、代码块、
  文字颜色、背景高亮、链接、图片（以 base64 内嵌）、分隔线、清除格式
- **两栏侧栏 + 三档视图（参考有道云笔记）**：最左侧有一条常驻**图标栏**（新建、🕘 最新、
  📌 置顶、📁 目录，底部为 **1 栏 / 2 栏 / 3 栏** 三个视图切换按钮与 **⚙ 设置** 入口）——
  **3 栏**＝目录树 + 笔记列表 + 编辑器，**2 栏**＝列表 + 编辑器，**1 栏**＝仅编辑器（状态记忆）。
  目录树为「🕘 最新 / 📌 置顶 / 📁 我的项目（可展开为 📂 分组）」，点击任一范围，
  右侧列表栏即显示该范围内的笔记（顶部为搜索框，`Ctrl+Shift+F` 可聚焦；底部显示「总共 N 项」）。
  项目/分组悬停出现 **✕** 可直接删除该层级（连同其中全部笔记，需确认；
  「默认项目 / 默认分组」为结构容器不可删除）。
  编辑区无独立标题框：**正文首行即标题**（类 macOS 备忘录，首行大字加粗，保存时取首行文字）；
  工具栏尾部右对齐处可选择项目与分组，下拉里可选已有项或「➕ 新建…」。
  未指定归属的笔记自动落入「默认项目 / 默认分组」；新建笔记会继承当前项目/分组，方便连续记录
- **置顶**：两种方式——列表项悬停出现 📌 按钮直接置顶/取消（立即生效）；
  或打开笔记后点编辑区的「📌 置顶」按钮（已保存的笔记点击立即生效，新笔记在保存时生效）
- **附件功能**（三种添加方式）：
  - 工具栏「📎 附件」按钮选择文件（可多选）
  - 在编辑器里直接 **Ctrl+V 粘贴**：截图/图片直接插入正文，其他文件（PDF/压缩包/文档等）自动加入附件
  - 把文件 **拖放** 到编辑器，效果同粘贴
  - 附件以 base64 随笔记一起存储（单文件 ≤ 10MB，正文图片 ≤ 4MB），附件栏可下载、可移除，
    侧栏笔记标题会显示 📎 数量标记；导出 HTML/Markdown 时附件以可下载链接形式包含
- 笔记管理：新建、保存、删除、按标题/正文全文搜索（本地即时过滤）
- 导出（导出按钮下拉可选三种格式）：
  - **HTML (.html)**：独立网页文件，保留全部样式
  - **Markdown (.md)**：转换为标准 Markdown（标题/加粗/斜体/删除线/行内代码/
    链接/图片/列表（含嵌套）/引用/代码块/分隔线；下划线和颜色高亮无对应语法，保留文字）
  - **PDF**：调用浏览器打印，目标选择「另存为 PDF」即可（Chrome/Edge 原生支持，
    中文渲染和分页效果最好；文件名取自笔记标题）
- 快捷键：`Ctrl+S` 保存

## 四、REST API（服务器模式）

| 方法   | 路径             | 说明                            |
|--------|------------------|---------------------------------|
| GET    | `/api/health`    | 健康检查                        |
| GET    | `/api/notes?q=`  | 笔记列表（q 为搜索关键词，可选）|
| GET    | `/api/notes/:id` | 获取单条笔记                    |
| POST   | `/api/notes`     | 保存笔记（带 id 更新，否则新建）|
| PUT    | `/api/notes/:id` | 更新指定笔记                    |
| DELETE | `/api/notes/:id` | 删除指定笔记                    |

笔记字段：`id`、`title`、`html`、`text`、`project`（项目）、`group`（分组）、
`pinned` / `pinnedAt`（置顶）、`attachments`（附件数组，JSON）、`createdAt`、`updatedAt`。
服务器表结构为 v1.1/v1.2 新增了这些列，旧版 `notes.db` 启动时会自动迁移（ALTER TABLE 补列）。

## 五、数据说明

- **本地模式**：数据保存在当前浏览器用户资料的 IndexedDB（库名 `rich-notes`）中。
  卸载扩展不会丢数据，但“清除浏览器数据”会一并清除，重要内容建议定期导出 HTML 备份。
- **服务器模式**：数据在 `server/notes.db`，可用任意 SQLite 客户端直接查看。
  端口可通过环境变量 `PORT` 修改，数据库路径可通过 `DB_FILE` 修改。
