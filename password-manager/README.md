# 本地密码库 —— 浏览器密码管理插件

一个 **纯本地** 的密码管理器浏览器扩展（Chrome / Edge，Manifest V3）。没有服务器、没有网络权限、不上传任何数据：所有密码用一个主密码通过 **AES-256-GCM + PBKDF2(600,000 迭代)** 加密后存在浏览器本地。

## 功能

| 功能 | 说明 |
|------|------|
| 主密码加密 | PBKDF2-SHA256 派生密钥，AES-256-GCM 加密整个密码库 |
| 条目管理 | 新增 / 编辑 / 删除（两步确认）/ 备注 |
| 搜索 | 按名称、用户名、网址、备注实时过滤 |
| 一键复制 | 列表快捷复制密码；详情页可复制用户名 / 密码 / 网址 |
| 密码生成器 | 自定义长度（8–64）、可选符号，排除易混淆字符，加密安全随机 |
| 自动填充 | 一键把用户名+密码填入当前页面的登录框（按需注入，无常驻脚本） |
| 自动锁定 | 5 分钟无操作自动锁定；也可手动立即锁定 |
| 备份 | 导出加密备份文件（.json，内容仍是密文）；导入恢复 |

## 安装（Chrome / Edge）

1. 打开扩展管理页：
   - Chrome 地址栏输入 `chrome://extensions`
   - Edge 地址栏输入 `edge://extensions`
2. 打开右上角的 **开发者模式**
3. 点击 **加载已解压的扩展程序**，选择本项目的 **`extension` 文件夹**
4. 工具栏出现 🔑 图标即安装成功。建议点击拼图图标 → 固定到工具栏

> 首次使用会要求设置主密码。**主密码无法找回**，忘记即无法解密数据（包括备份文件），请务必牢记。

## 日常使用

1. 点击工具栏图标 → 输入主密码解锁（同一浏览器会话内重新打开不需要重复解锁，5 分钟无操作后自动锁定）
2. **＋** 新增条目：填名称/网址/用户名，点 **生成** 自动生成强密码，保存
3. 在网站登录页：打开插件 → 点开条目 → **自动填充当前页**
4. 列表页每条右侧 **复制密码** 可直接粘贴使用
5. 定期 **导出备份**，把加密备份文件存到安全位置（U盘/私人网盘）；换电脑时用 **导入备份** 恢复（导入后需用备份时的主密码解锁）

## 安全设计

- **静态加密**：密码库以 `{"v":1,"salt","iter","iv","data"}` 存于 `chrome.storage.local`，`data` 为 AES-256-GCM 密文，每次保存使用新随机 IV
- **密钥派生**：PBKDF2-HMAC-SHA256，600,000 次迭代 + 16 字节随机盐（OWASP 推荐值）
- **解锁状态**：派生密钥仅存于 `chrome.storage.session`（内存，浏览器关闭即清空，不落盘）
- **口令校验**：不存储任何"密码提示"；错误主密码由 GCM 认证标签直接拒绝
- **最小权限**：仅 `storage / alarms / activeTab / scripting / downloads`，无任何 `host_permissions`，不请求任何网站的常驻访问权；自动填充脚本只在点击按钮那一刻注入当前标签页
- 详见 `extension/vault.js`（加密模块）、`extension/background.js`（自动锁定）

### 注意事项

- 备份文件同样是密文，**与主密码同等重要**，两者缺一不可恢复
- 复制到剪贴板后不会自动清空（跟随系统剪贴板策略）
- 浏览器内插件处于解锁状态时，同一电脑的其他使用者可查看；离开电脑请手动点 🔒 锁定
- `chrome://` 等浏览器内部页面不支持自动填充（浏览器限制）

## 常见问题

**忘记主密码怎么办？**
无法找回。只能记住备份文件 + 主密码，否则数据永久无法解密。

**换电脑怎么迁移？**
新浏览器装好插件 → 导入备份文件 → 用原主密码解锁。

**能在 Firefox 用吗？**
当前面向 Chromium（Chrome/Edge/Brave 等）。Firefox 的 MV3 背景脚本机制不同，需少量适配（未测试）。

**数据存在哪里？**
`chrome.storage.local`，随浏览器用户配置目录存储，可通过导出备份随时带走。
